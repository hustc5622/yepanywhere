# 内网单用户实例的明文展示

本发行线按仅供所有者使用的内网实例维护，不再按字段名、内容模式或文件位置遮盖展示数据。

## 保留原文的范围

- provider 事件、JSONL 历史、SDK 日志及 transcript 导出中的路径、输入输出、凭据、错误详情和 provider 已提供的推理文本。
- 附件提示及本地媒体的原始路径；bridge 状态中的 URL、启动参数及诊断信息。
- 飞书消息、交互卡片、待发送记录、位置坐标和有容量上限的原生工具详情；已认证设置 API 返回完整 App Secret。
- 生成附件不再因文件名、文本或图片提示含有密钥字样而被拦截。

## 仍保留的限制

认证授权、审批流程、文件访问范围和符号链接检查、附件来源及哈希校验、危险归档检查、HTML 转义和活动 URL 协议校验均不变。支持的附件格式、字符串/集合/深度上限、导出及日志容量限制也不变。生成图片的二进制正文仍走独立附件通道，不重复写入事件日志。

旧日志里的脱敏计数和占位符继续兼容读取。文件路径可通过同一工具调用的路径指纹与原始会话精确匹配后恢复；只剩指纹或占位符的数据无法反推出原文。

## 使用范围

访问控制不等于内容脱敏。日志、导出文件、下载附件和飞书卡片可能包含完整凭据或本机路径。分享这些内容之前需由所有者自行检查；若将实例开放给其他用户或公网，应先重新评估这一默认行为。

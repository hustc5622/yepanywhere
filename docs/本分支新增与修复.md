# 本分支新增与修复说明

> 本仓库基于 [kzahel/yepanywhere](https://github.com/kzahel/yepanywhere) 继续开发，本页只说明当前分支的二次开发内容与维护改进。

## 新增与完善

- **前端检查更新**：设置页会刷新部署信息并比较当前运行版本、本地工作树和远程 GitHub 提交。
- **更新到本地最新**：设置页可用当前工作树重新构建生产 Bundle 并重启生产服务。
- **更新到 GitHub 最新**：设置页可拉取远程代码、完成构建校验并重启生产服务。
- **跨平台服务管理**：`pnpm yep` 会在 Windows 调用 PowerShell 脚本、在 macOS 调用 Bash 脚本，并提供相同的中文命令和菜单。
- **后台与自启动**：开发服务默认脱离启动终端后台运行，生产服务可通过 Windows 计划任务或 macOS LaunchAgent 登录自启。
- **安全重构建**：生产重构建先在暂存目录完成 Bundle、运行时依赖和校验，成功后才替换现有生产版本。
- **管理员密码**：`pnpm yep setup-admin-password` 设置或重置当前系统用户共享的管理员密码，且不接受命令行明文密码。
- **普通登录密码**：普通密码只能从服务器本机的“设置 → 本地访问”启用、修改或关闭，远程用户只能使用普通密码登录。
- **会话仓库浏览**：会话检查器提供仓库树、文件类型图标、手动刷新和实时文件变更刷新。
- **模型与思考程度**：新建会话和会话检查器都可选择模型，思考程度按各提供商的原生可用档位显示和传递。
- **会话模型预设**：未运行的会话可以保存模型预设，并在下次启动时生效。
- **多标签文件工作区**：聊天与多个文件标签可共存，文本文件支持编辑、保存、未保存提示和快捷键保存。
- **独立文件页面**：任意文件可在新浏览器标签页打开，并支持复制、下载和全屏查看。
- **Markdown 渲染**：Markdown 支持标题锚点与目录、列表、引用、任务项、代码块、表格和常见行内格式。
- **常用格式预览**：PDF 使用浏览器预览，DOCX 使用文档渲染，CSV/TSV 与 XLS/XLSX 以可滚动表格展示。
- **服务端目录选择**：新增项目时可从服务实际运行的设备浏览目录，不再依赖桌面端专用文件选择器。

## 已修复问题

- **Windows 更新可靠性**：修复更新到本地或 GitHub 时因 PowerShell 子进程、文件锁和 `npm ci` 清理导致的假成功或失败。
- **更新检测准确性**：更新检测会刷新远程提交并按提交哈希比较，避免仅按日期比较造成漏报或误报。
- **部署隔离**：开发模式不会误重启生产服务，失败的暂存构建不会覆盖现有 Bundle 或中断在线服务。
- **服务脚本健壮性**：修复 Windows 计划任务身份识别、受管进程清理、macOS LaunchAgent 安装错误和运行模式误判。
- **文件渲染稳定性**：修复 Markdown 表格渲染崩溃和退化布局，并修正本地图片、文档与表格预览路径。
- **会话页面容错**：会话不存在或字段缺失时显示错误界面，避免 `undefined` 访问导致页面崩溃。
- **发送状态恢复**：WebSocket 异常关闭或长时间无响应时会恢复会话状态，避免界面长期停留在 Pondering。
- **Codex 兼容性**：Codex 会话沿用本机默认 provider，支持自定义 CLI 路径，并兼容不同来源的会话数据。
- **会话索引兼容性**：修复 Codex 会话来源、清单和索引解析差异，改善跨平台会话发现与显示。

## 使用入口

- **更新与版本信息**：打开“设置 → 关于”，使用“检查更新”“更新到本地最新版本”或“更新到 GitHub 最新版本”。
- **服务管理**：在仓库根目录运行 `pnpm yep` 打开菜单，或运行 `pnpm yep help` 查看命令列表。
- **密码管理**：先运行 `pnpm yep setup-admin-password`，再从服务器本机打开“设置 → 本地访问”。
- **仓库和文件**：打开会话右侧检查器的“文件”页签，再选择文件在会话工作区或独立标签页中查看。

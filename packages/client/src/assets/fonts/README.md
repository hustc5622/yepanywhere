# 终端字体

`JetBrainsMonoNLNerdFontMono-Regular.ttf` 来自 Nerd Fonts v3.4.0：
https://github.com/ryanoasis/nerd-fonts/blob/v3.4.0/patched-fonts/JetBrainsMono/NoLigatures/Regular/JetBrainsMonoNLNerdFontMono-Regular.ttf

采用无连字、单格图标版本，供 xterm 展示 Oh My Zsh / Powerline / Nerd Font 提示符。
字体随客户端构建发布，仅在终端页面加载，不依赖手机系统字体或外部 CDN。
授权文件位于 `packages/client/public/licenses/terminal-fonts/`，会随构建产物发布：
原字体授权见 `OFL-JetBrainsMono.txt`，Nerd Fonts 图标与补丁授权见 `LICENSE-NerdFonts.txt`。
